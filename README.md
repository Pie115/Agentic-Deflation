# Agentic Matrix Deflation

## Abstract

Can a small team of agents peel a matrix apart, one rank-1 slice at a time? We study an agentic approach to matrix deflation in which a solver large language model (LLM) proposes rank-1 singular value decomposition (SVD) updates, and a vision language model (VLM) accepts or rejects each proposal and adaptively decides when to stop, removing the need for fixed norm thresholds. To stabilize the solver, we use in-context learning (ICL) examples and investigate various permutation strategies that reorder matrix rows and columns to expose visually coherent structure. We evaluate on three image-like settings: \textsc{Digits} ($8{\times}8$), \textsc{CIFAR-10} ($32{\times}32$ grayscale), and synthetic ($16{\times}16$) matrices with and without Gaussian noise. For the synthetic noisy setting, where the construction rank $k$ is known, our precise numerical implementation deflates exactly $k$ steps and the remaining noise serves as the ground truth target. Our agent’s residuals come close, with the best configuration achieving an RMSE difference of just $1.75$. For \textsc{Digits} and \textsc{CIFAR-10}, we define targets by deflating until the residual Frobenius norm reaches $10\%$ of the original. Across all settings, the agentic framework yields competitive results, suggesting that fully agentic deflation, without any norm thresholding, can serve as a viable alternative to traditional numerical pipelines.
